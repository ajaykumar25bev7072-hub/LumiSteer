# LumiSteer — AI agent for stable IRS-assisted VLC links

An indoor **Visible Light Communication (VLC)** simulator with a wall-mounted
**Intelligent Reflecting Surface (IRS)**. A deterministic NumPy physics engine
computes every number (power, irradiance, SNR, BER). An **NVIDIA Nemotron**
agent served through **Nebius Token Factory** diagnoses link degradation,
selects classical optimization tools, and explains what happened — the LLM
never computes a metric itself.

> Hackathon track: Physical AI · Nebius x NVIDIA Global AI Hackathon (Devpost)

## Quick start

Requirements: Python 3.11+ (3.14 tested) and Node 18+.

```bash
# 1) backend
cd backend
python -m pip install -r requirements.txt
python -m pytest tests -q          # optional: run the physics unit tests
uvicorn app.main:app --reload --port 8000

# 2) frontend (new terminal)
cd frontend
npm install
npm run dev                        # http://localhost:5173, proxies /api to :8000
```

Opening http://localhost:5173 gives you the landing page; "Launch simulator"
is the main working area.

### Environment variables

The LLM agent reads three variables (never hardcoded, never sent to the
browser) — see `.env.example` at the repo root:

| Variable | Purpose | Default |
|---|---|---|
| `NEBIUS_API_KEY` | Token Factory API key (https://api.tokenfactory.nebius.com → API keys) | — |
| `NEBIUS_BASE_URL` | OpenAI-compatible endpoint | `https://api.tokenfactory.nebius.com/v1` |
| `NEBIUS_MODEL` | NVIDIA model id (check the model list; Nemotron required by the hackathon) | `nvidia/Llama-3_3-Nemotron-Super-49B-v1_5` |

**Without a key the app still works fully**: every physics/optimization button
is classical code, and "Run agent" replays a labelled **demo cache** (a saved
agent run) so demos never depend on API uptime.

## What's inside

```
backend/
  app/
    schemas.py          Pydantic config + API models (all defaults live here)
    physics.py          vectorized channel model: LOS, IRS reflection, noise, OOK BER
    optimizers.py       optimize_irs (L-BFGS-B), robust_optimize, baselines
    strategies.py       4-strategy comparison + scripted blockage timeline
    predictor.py        classical blockage-risk predictor (no LLM)
    agent.py            Nemotron agent loop: tool calling, JSON fallback, cap=4
    main.py             FastAPI endpoints (+SSE agent streaming), CORS
    demo_cache.json     replayed agent demo run (generated by scripts/gen_demo_cache.py)
    export.py           CSV / Markdown report export
  tests/                unit tests (LOS monotonic in distance, BER monotonic in
                        SNR, blockage isolates the IRS path, optimized >= random,
                        40x40 sweep < 3 s, API smoke tests)
frontend/
  src/pages/            Landing · Simulator · Comparison · Timeline · Methodology
  src/components/       RoomView (draggable RX + blocker), MetricsCards,
                        ControlPanel, AgentConsole, Heatmap (colorblind-safe)
docker-compose.yml      one-shot: backend :8000 + frontend :5173
```

## Demo script (2 minutes)

1. **Simulator**: show Stable link; drag the receiver — metrics update live.
2. Click **Block the direct path** → status flips to Outage, BER explodes.
3. Click **▶ Run agent** → agent console streams: observe → "direct path
   blocked" tool calls (simulate, robust_optimize) → final explanation quoting
   only tool numbers; the IRS re-steers and the link recovers.
4. **Comparison** page: four BER heatmaps (no IRS / random / fixed-point /
   agent-robust) + outage bars; strategy D never worse than A/B in the default
   scenarios.
5. **Blockage timeline**: scripted walk of a person across the beam with
   agent re-steering events marked; blockage-risk predictor chart.
6. **Methodology** page: every formula and default; how the LLM is and isn't used.

## Deployment notes

- Frontend → Vercel/Netlify: build with `npm run build`, set
  `VITE_API_BASE` to the backend URL.
- Backend → Render/Railway: start command
  `uvicorn app.main:app --host 0.0.0.0 --port $PORT`, set the `NEBIUS_*`
  variables in the dashboard, set `CORS_ORIGINS` to your frontend origin.
- Or simply `docker compose up --build`.

## Assumptions & limitations

Simulation only; simplified IRS model (specular elements + Gaussian alignment
factor, no inter-element scattering); ambient background is position-independent;
photometric conversion uses a single efficacy. See the in-app **Methodology**
page for every formula and default parameter.
